# Spring Boot & Infra Study Project

간단한 백엔드 애플리케이션 구현을 통해 Spring Boot에 익숙해지고, 백엔드 애플리케이션을 통해 각종 인프라 환경을 구성해보며 학습하기 위한 프로젝트입니다.

## 프로젝트 구성

### Community Backend

Spring Boot로 구현된 커뮤니티 백엔드 애플리케이션

- Spring Boot Version: 3.5.8
- DB: MariaDB 11.4
- ORM: Spring Data JPA
